# Câu mở session mẫu (dán vào session mới)

Dùng skill channel-video. Tập: <id hoặc tên tập>. Việc: <dàn ý / kịch bản / dựng chương N / ảnh bìa / bài đăng / shorts>.
Đọc `studio-kit/AGENTS.md`, `channel-example/skill/SKILL.md` và reference của bước này (chung + riêng), rồi STATUS.md phần của tập. Tự làm hết phần được giao, tự soát theo tu-soat.md, xong mới báo. VBee: báo số ký tự trước khi gọi.

---
Ví dụ:
- "Dùng skill channel-video. Tập mới: Xếp hạng yêu quái Tây Du Ký. Làm dàn ý + kịch bản, hiện trong chat."
- "Dùng skill channel-video. Tập cuoc-doi-quan-vu: dựng hình chương 2–5 theo mốc ước lượng, gửi clip từng chương."
- "Dùng skill channel-video. Tập xu-an-tao-thao: làm 3 phương án ảnh bìa."
