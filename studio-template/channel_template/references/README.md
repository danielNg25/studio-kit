# References

Each reference gets one short note (copy `_TEMPLATE.md`). Notes, not just files — the point is *what we learn*.

- `content/` — source videos we take topics/structure from. Rule: take the topic and the structure, **rewrite** every line, re-check every number.
- `style/` — the visual look we copy (frames + measured style). The measured result lives in the style pack.
- `competitors/` — channels in the same space. What wins, why, what we do differently. Patterns that win go back into `blueprint.yaml`.
